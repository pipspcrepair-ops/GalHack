# Families built by the architect. Same format as families.txt; these name a building program
# (data/programs.txt) or a site plan (data/sites.txt) instead of a kit. Their variants are named
# seeds: a fixed seed always gives the same place, and any other seed gives a new one.
#
#   program <id> | site <id>   what builds it (a variant may name its own)
#   core owned|none            a core only where a faction holds the place
#   owner faction|gang|none    gangs belong to no faction: always hostile, no standing
#   ominous <0..1>             how much worse it gets deeper down
#   wrong <0..1>               the share of spawns that are deliberately wrong
#   tags                       theme tags (placement themes and loot weighting)
#   landmark                   a hand-authored site plan with a strong identity
#   pitch                      one line: why you'd want to go there
