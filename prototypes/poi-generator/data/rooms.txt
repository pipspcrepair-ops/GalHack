# The shared room library. Every architect-built place (bunkers, hospitals, towers, research
# bases, prisons, cryo vaults, spaceport terminals, ships...) is a recipe of these rooms; a style
# kit re-skins them, so one cryo bay is a colony ship's, a vault's or a prison infirmary's.
#
#   room <id>
#     name        what it's called
#     kind        room, hall or vault (what the dressing and the validator treat it as)
#     width a b   interior width along the corridor it prefers, in cells
#     area a b    the floor area it wants, m2: planning practice for its purpose (data/references.txt)
#     props       perimeter furniture and weights: bench machine shelf locker crate table bunk
#                 bed pod tank statue crystal cell pillar barricade planter screen
#     fill        share of the wall cells that get furniture
#     island      furniture in rows across the middle of big rooms (pod rows, bed rows, tables)
#     near/avoid  rooms it should and shouldn't share a wall with (or face across the corridor)
#     prefer      any, entrance (near the way in), end (far from the stair), core (by the stair)
#     loot a b    caches; terminals a b; spawns a b
#     light       warm, cold, dim, red, green, cryo, glyph, none
#     lock        the keycard clearance its door needs: staff, science, security, command
#     blast       its door is a blast door
#     deco        the decorations library's set for it (proto/deco), beside the generic props
#     tags        keyspot (a keycard may be left here), core (a faction's core goes here),
#                 hum, cluster (likes its own kind next door), and loot tags (medical, military...)
