# POI families. Each family is one name with 3 to 6 layouts; each layout has a fixed seed, so
# it's always the same building, and the dressing pass (state, loot, enemies, logs) varies
# per spawn.
#
#   faction <id>          meridian, exchange, vharn, kessari, reavers, freeholders, hollow,
#                         or none for ruins nobody living built
#   roster <section>      rosters.txt section for its defenders (default: the faction id)
#   kit <kit> [tag]       the faction kit (and module tag) the layout is built from
#   deep <kit> [tag]      a second kit for steps written "deep:<kind>" (deeper levels)
#   rarity                common, uncommon, rare, exotic or unique (the rarity ladder)
#   biomes                desert rock ash ice steppe fungal
#   territory             faction territories it can spawn in, "wild" (no one's), or "any"
#   near/avoid <f> <r>    within / beyond r map cells of f: "deposits", "territory:<faction>",
#                         or another family's id
#   spacing <r>           map cells to the nearest place of the same family
#   reveal <m>|landmark   how close you must be before it shows on the map; landmarks show
#                         from orbit
#   states                weights for active, abandoned, infested and ruined spawns
#   damage <0..1>         baseline wreckage even when active (crash sites)
#
#   variant <name>
#     seed <n>
#     path <steps>        entrance ... vault; a step is [deep:]kind[*min-max]
#     branches <a-b> <chains>   optional side branches, a chain is kind>kind
#     grow <kinds>        extra steps inserted before the vault as rarity goes up
