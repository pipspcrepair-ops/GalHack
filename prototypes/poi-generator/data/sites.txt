# Site plans: hand-authored landmarks, the Empyrion way. Each plan places its parts (buildings
# from data/programs.txt, and yard features) in site cells, metres from the site origin; the
# buildings' rooms are planned with the family variant's seed, so a landmark is always the same
# place. Buildings face west (their way in is on their west side) unless turned with rot.
#
#   site <id>
#     style      the kit the yard and buildings use unless a part names its own
#     entrance   x z facing      where you arrive
#     part <kind> <x> <z> [rot n] [key value]...
#       building  program <id> [w d floors levels style vault yes]   vault yes: it holds the prize
#       runway    len width axis cracks;  road  len width axis;  pad  r
#       tanks     count r h gap axis;  stacks  count r h gap type;  containers  rows cols
#       fence     len h axis gate breaches type(mesh|wall);  poles  count gap h axis
#       tower     h size every crown(lamp|wheel|hut) loot;  crater  r depth radiation
#       aircraft  len;  rocket  decks r;  trench  len axis;  vehicles  count gap axis
#       camp      gang(yes|no);  obelisks  count h spread
