# kind:          guard, turret, hover, boss (faction defenders), hollow (Hollow Bloom creatures),
#                fauna (wildlife that moves into empty places)
# shooter-class: the combat system's class for this shooter. It starts with warning shots,
#                ramps accuracy toward a class-versus-target baseline, and capital-class rounds
#                fly slowly enough to dodge.
#                  none          doesn't shoot (melee, swarms)
#                  infantry      on foot
#                  small-vessel  hover drones, skimmers, light turret guns
#                  capital       base and fortress emplacements, the heaviest bosses
# weapon:        a weapon id the combat code looks up.
#

# "Bloom-ridden" prefix at spawn time.
