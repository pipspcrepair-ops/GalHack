# World layers: a world rolls one world type, one theme, some features and maybe a presence, and
# they combine. Memorable worlds come from combinations, not bespoke entries: a swamp world, plus a
# crash-site feature, plus a pirate presence overhead gives a swamp of crashed ships under a patrolling
# pirate ship, without anyone writing that world by hand. Every table here adds to the others.
#
#   type|theme|feature|presence <id>
#     name      the player-facing words for it
#     weight    how often it is rolled, among its kind that fit (rarity)
#     chance    feature and presence: the chance a world has it at all
#     worlds    planet archetypes it can sit on (temperate arid ice lava alien), or any
#     start     yes: it can be a start world
#     pre, post tech bands it fits, before and after the collapse (L M H)
#     ports     starport classes it fits (A B C D E 0)
#     region    what the region planner lays down: town N, port_hub N, farmland N, industry N, hamlet N,
#               camp N, scrappy_pad N, wreck_field N (N a count, per world)
#     style     road <jammed|haul|quiet|track>, rail <none|derelict|trunk>, power <none|port_only|intact|pylons>
#     hub       what stands at the heart of a town, weighted
#     needs     what every town had to have, in the order it's built (sewage_works water_works ...)
#     industry  what a town lived on, weighted
#     plant     what fed a town's lines, weighted
#     depot     where a town's railway ended
#     farm      what stood on its farmland, weighted
#     poi       more places on the theme, weighted, set down in its regions
#     break     the share of a world's places that break from the theme
#     state     active abandoned infested ruined: replaces the families' own odds
#     occ       who's in a place (docs/world-themes.md, Occupancy): shares by code; A/B is a mixed place
#     streets   how many streets of houses a town gets
#     tags      what decorations and loot can key on
#
# Unknown family names are skipped with a warning, so new families can be added a theme at a time.
