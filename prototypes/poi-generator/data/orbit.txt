# Places in space: data and siting only for now (orbit play and space layouts come later).
#
#   space <id>        a kind of place in space
#     kind            wreck, field (a wreck field), hulk (a drifting hulk), broken (a broken station),
#                     station or outpost. The first four are wrecks: salvage, nobody home.
#     rarity          common .. unique
#     danger          0 calm .. 4 deadly
#     salvage         scrap, salvage, military or rare
#     faction / held  who holds it while it's live (its core and defenders)
#     zones           near (close to the start world), orbit, moon, belt, deep
#
#   orbit <id>        how a system's space is filled
#     match           default, or start (a start system)
#     sites min max   how many places
#     wrecks share min N   the share that are wrecks, and at least N of them
#     danger          the most dangerous kind allowed
#     nofactions      no live faction anywhere: held places only as dead wrecks
